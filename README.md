# flower_petal.py

A Python script using the `turtle` library and Bézier curves to draw a beautiful, filled flower.

## Features
- **Bézier Curves**: Custom implementation of quadratic Bézier curves to draw smooth petal outlines.
- **Symmetrical Design**: Mathematical plotting of petal shapes around a center.
- **Customizable**: Control number of petals, sizes, and colors easily.

## Requirements
- Python 3.x
- `turtle` and `math` (standard Python modules)

## Usage
Run the script to view the turtle drawing:
```bash
python import.py
```
